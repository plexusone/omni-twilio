## [v0.10.0] - 2026-10-27

### Highlights

- Keypad digits (DTMF) on answered outbound calls, for example to join a meeting's phone dial-in line
- Gateway call options through omnivoice-core's `OptionCaller` interface

### Added

- `MakeCall` honors `callsystem.WithSendDigits`, playing the digits with `<Play digits>` before `<Connect><Stream>` ([`89f2eef`](https://github.com/plexusone/omni-twilio/commit/89f2eef))
- Gateway `MakeCallWithOptions` implementing omnivoice-core `gateway.OptionCaller` ([`89f2eef`](https://github.com/plexusone/omni-twilio/commit/89f2eef))

### Fixed

- OmniMemory provider uses `ObservationCreateRequest`, renamed from `ObservationCore` in twilio-go v1.32 ([`58368ed`](https://github.com/plexusone/omni-twilio/commit/58368ed))

## [v0.7.0] - 2026-06-15

### Highlights

- Realtime voice-to-voice pipeline with ~100-200ms latency
- Dual pipeline modes: text (STT→LLM→TTS) or realtime (voice-to-voice)
- LLM provider injection via `LLMClient` config field

### Added

- `Mode` config field to select pipeline mode (`text` or `realtime`) ([`6a5fedb`](https://github.com/plexusone/omni-twilio/commit/6a5fedb))

- `RealtimeConfig` config field for realtime session configuration ([`6a5fedb`](https://github.com/plexusone/omni-twilio/commit/6a5fedb))
- RealtimeBridge integration for native voice-to-voice conversations ([`6a5fedb`](https://github.com/plexusone/omni-twilio/commit/6a5fedb))
- Support for OpenAI Realtime API (~100ms latency) ([`6a5fedb`](https://github.com/plexusone/omni-twilio/commit/6a5fedb))
- Support for Gemini Live API (~200ms latency) ([`6a5fedb`](https://github.com/plexusone/omni-twilio/commit/6a5fedb))
- `LLMClient` config field for injecting pre-configured LLM providers ([`13167fb`](https://github.com/plexusone/omni-twilio/commit/13167fb))

### Changed

- LLM provider creation uses omnillm-core registry (thin providers) by default ([`13167fb`](https://github.com/plexusone/omni-twilio/commit/13167fb))

### Dependencies
